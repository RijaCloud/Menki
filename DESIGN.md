# Direction de l'interface

Référence principale fournie par l'utilisateur, Boubou Desktop, pour la densité,
les projets comme dossiers et la conversation comme entrée des actions.

Références complémentaires consultées via Refero

- Obsidian, style c089500f-32b2-4821-baad-a08ea2b625d8, pour les surfaces sombres,
  les textes lisibles et le violet réservé aux actions.
- Factory, écran 25a3e885-0d43-4221-b14f-bc8168108ebb, pour les outils et étapes
  repliables dans une conversation.
- ChatGPT, écran 4180bcdd-87a8-402d-b107-c7e400b4369a, pour le compositeur.

Le centre est le fil. Une barre latérale étroite peut se replier. Le panneau
de droite est contextuel et fermé au départ. Pas de grand bandeau d'accueil.
Police Inter avec fallback système, fond #101113, surfaces #191b20, texte
#ececf1, action violette #7c3aed. Animations de 160 ms, mouvement réduit respecté.
