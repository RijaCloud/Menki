# Menki local

Application Windows locale, React/TypeScript/Fastify/SQLite et Codex App Server officiel.
L'état utilisateur est stocké sous LOCALAPPDATA/Menki. Les outils agent passent par
le service local. Les écritures sont bornées aux dossiers accordés au projet.
Les identifiants Codex sont gérés par Codex, hors des projets.

Ne jamais modifier les services VPS, Workat, les dépôts voisins ou leurs credentials
pour les essais de Menki. Utiliser les deux espaces pilotes.
Vérifier types, tests de frontières et parcours réel avant de livrer.
